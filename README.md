# Housing Price Prediction App

A Flask Machine Learning web application that predicts California housing prices using Random Forest Regression.

## Features
- Flask Web App
- Machine Learning Pipeline
- Random Forest Regressor
- Data Preprocessing
- House Price Prediction

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy

## Deployment
Hosted on Render.

## Run Locally

```bash
pip install -r requirements.txt
python app.py
